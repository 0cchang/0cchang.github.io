At the AI + Security Lab at UMIACS, I developed testing infrastructure for evaluating security flaws in code generated by multi-turn language model agents. The goal was to make security regressions measurable and reproducible rather than anecdotal.

This will become a detailed write-up of the threat model, test design, and the gaps that still need better evaluation.
