During my summer in Austin, I worked on full-stack search functionality for the Amazon Pharmacy order history page. The feature was designed for a large customer base, so I focused on clear contracts between the frontend and backend, predictable query behavior, and an experience that remained useful as order histories grew.

This is where I will write about the design decisions, testing strategy, and lessons from shipping the feature.
